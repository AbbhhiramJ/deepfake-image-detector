# AI-Generated Image Detector

A Streamlit research prototype for classifying uploaded images with a pretrained Hugging Face vision model.

This app is intended for demonstration only. It is not forensic proof and may misclassify images, especially unseen generators or compressed/edited images.

See `PRESENTATION_BRIEF.md` for the project objective, architecture, evaluation plan, research papers, and future methodology.
